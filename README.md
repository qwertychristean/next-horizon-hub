# Next Horizon Hub

A Vite React app for Next Horizon Hub with Tailwind CSS, React Router, and lucide-react.

## Pages
- `/` → Landing page for *The Reclaim Your Time AI Guide*
- `/success` → Success page after form submission

## Setup

1. Open the project folder in VS Code:
   ```bash
   cd ~/next-horizon-hub
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
